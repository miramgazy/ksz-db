# KSZ Companion Helper (Локальный агент инженера)
## Версия 2.0.0 (Client-Server RDS Edition)

**KSZ Companion Helper** — это клиентский фоновый агент, предназначенный для работы на рабочем месте инженера или на терминальном сервере **Windows Server (RDP / RDS)**.

Агент связывает веб-интерфейс **KSZ-DB** с локальным окружением пользователя:
1. **Запуск iikoBackOffice** через протокол `clearbat://` в один клик.
2. **Прямое внесение клиента в локальную базу ClearBat** (`Entities.sqlite`) без ручного ввода.
3. **Обновление лицензий** заведения через ClearBat.
4. **Быстрый запуск AnyDesk** (напрямую или через песочницу Sandboxie).
5. **Автоматическое копирование паролей** в буфер обмена инженера.

---

### Архитектура v2.0 в терминальной среде (RDS / Windows Server)

В отличие от старых решений, агент **не слушает локальные TCP-порты** (например, `48123`), что гарантирует:
* **Полное отсутствие конфликтов портов**: десятки инженеров могут одновременно работать на одном физическом сервере Windows Server 2019 в разных RDP-сессиях.
* **Изоляцию сессий**: AnyDesk, ClearBat и буфер обмена открываются строго на мониторе того инженера, который нажал кнопку в браузере.
* **Работа без сторонних библиотек**: агент написан на стандартной библиотеке Python и не требует установки сторонних пакетов через `pip`.

---

### Быстрый запуск для инженера

1. Запустите файл:
   ```cmd
   run_agent.bat
   ```
2. При первом запуске скрипт запросит:
   * **Адрес API сервера** (по умолчанию `http://127.0.0.1:8000/api/v1` или адрес вашего сервера KSZ-DB).
   * **Логин** и **пароль** вашей учетной записи в KSZ-DB.
3. Данные сохранятся в файл `ksz_helper.ini`, и в дальнейшем агент будет подключаться автоматически в 1 клик.
4. В шапке веб-интерфейса KSZ-DB загорится зелёный индикатор **«Агент активен»**.

---

### Файл настроек `ksz_helper.ini`

После первого запуска создается файл конфигурации:
```ini
[SERVER]
api_url = http://127.0.0.1:8000/api/v1
username = ivan
password = *********

[SETTINGS]
clearbat_db_path = C:/ClearBat/ClearBat.db
sandman_path = C:\Program Files\Sandboxie-Plus\SandMan.exe
default_anydesk_exe = C:\Program Files (x86)\AnyDesk\AnyDesk.exe
```

Если база ClearBat или утилита Sandboxie установлены по нестандартному пути, укажите актуальные пути в секции `[SETTINGS]`.
